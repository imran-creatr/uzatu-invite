## Анимации

Всё построено на классах, а не на inline-стилях: JS помечает элемент
`.reveal` и задержкой `--d`, затем ставит `.is-in` при появлении в
экране. За то, *как* именно выезжает элемент, отвечает CSS — поэтому
любой тип элемента настраивается отдельно.

- Hero — строки выходят каскадом (заголовок → разделители → дата → имя),
  разделители «прочерчиваются» через `scaleX`, имя потом едва дышит.
- Разделители и `hairline` растут из центра, орнаменты — с лёгким масштабом,
  у разреженных заголовков собирается трекинг.
- Цветочные орнаменты не замирают после появления: розетка календаря дышит,
  гирлянды сносит вверх-вниз, росчерки в hero чуть растягиваются. Периоды разные (8.5–12.5 с) и задержки перебивают
  reveal, чтобы ничего не пульсировало в унисон и не прыгало на старте.
- Календарь — клетки всплывают волной по диагонали, сердце на 14-м числе
  обводится по контуру (реальная длина пути через `getTotalLength`), затем
  медленно пульсирует.
- Таймер — настоящие flip-карточки: передняя створка складывается вниз,
  задняя поднимается за ней, обе с затенением на повороте. Крупные разряды
  дополнительно чуть «клюют» на переключении; секунды — нет, иначе блок
  дёргается каждую секунду. Карточки не листаются, пока таймер вне экрана.
  Цифры — `lining-nums`: в Cormorant по умолчанию старостильные цифры, где
  3 5 7 9 свисают под базовую линию, а 6 8 торчат вверх, поэтому каждая
  сидела на своей высоте и шов резал их по-разному. Ровные цифры одной
  высоты центрируются в карточке сами (центр очка — 30.1 при высоте 60),
  никакого сдвига не нужно.
- Кнопки — подъём, тень и блик; радио — упругая точка; поле ввода —
  подчёркивание растёт из центра; ошибка формы — короткий nudge.
- `prefers-reduced-motion: reduce` выключает всё движение и принудительно
  показывает каждый элемент.

## Ответы RSVP

Форма собирает **имя** и **ответ** (приду / приду с супругом / не смогу) и
отправляет их POST-запросом на веб-приложение Apps Script — URL задан в
`RSVP_ENDPOINT` в начале [app.js](assets/js/app.js). Тело — JSON `{ name, answer }`.

Заголовок `Content-Type` намеренно **не** выставляется: `fetch` со строковым
телом сам помечает его как `text/plain`, и запрос остаётся «простым». Стоит
указать тип явно — браузер шлёт preflight `OPTIONS`, на который Apps Script
не отвечает, и запрос падает по CORS.

Логики записи в таблицу по её ссылке на стороне сайта нет — приёмник живёт
в Apps Script, сайт только отправляет ответ.

Локально ответ всё равно дублируется в `localStorage` (`uzatu-rsvp`). Если
отправка не удалась (нет сети), ответ кладётся в очередь
`uzatu-rsvp-pending` и уходит при следующем открытии страницы.

## Ассеты

Все картинки и видео — настоящие, из design-проекта. Иллюстрация зала
(`assets/img/venue.png`, 639×364) сверена с проектом побайтово.

Единственная заглушка — **фон бумажных блоков** `assets/img/paper.svg`:
процедурная имитация рваного листа. Чтобы поставить настоящую текстуру,
положите файл в `assets/img/` и поменяйте одну строку в `styles.css`:

```css
--paper: url('../img/paper.png');
```

Фон общий для блоков 2 «Шақыру» и 5 «Өтетін орны» — меняется
одним значением сразу для всех трёх.

## Шрифты и цвет

Cormorant Garamond — вся типографика; других шрифтов на странице нет.

Имя «Арайлым» — не текст, а готовая каллиграфия
`assets/img/name-arailym.png` (820×296, прозрачный фон). Исходник был
1698×926 с широкими пустыми полями: обрезал по чернилам (минус 38% площади)
и уменьшил под retina — 88 КБ вместо 299. В `alt` лежит само имя, так что
без картинки оно всё равно прочитается.

Тон чернил в каллиграфии — `#683900`, практически тот же коричневый, что и
текст `#684108`.

Весь текст — `#684108` (`--gold`), включая цифры календаря и дни недели.
Тот же цвет в rgba-подсказках берётся из `--gold-rgb`, чтобы значение
жило в одном месте. Сердце на 14-м числе рисуется через `currentColor`,
то есть само следует за цветом текста.
